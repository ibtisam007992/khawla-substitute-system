# منظومة الاحتياط المدرسي الذكي

نظام ويب لإدارة حصص الاحتياط المدرسي، مع حسابات وصلاحيات، وتنبيهات صوتية، وإحصائيات الغياب، واستيراد الجدول العام من ملف PDF (aSc Timetables).

**تم إنشاء هذا النظام بواسطة معلمة تقنية المعلومات ابتسام الرواس**
مدرسة خولة بنت حكيم للبنات (9-12) — وزارة التعليم، سلطنة عمان

## المزايا
- توزيع الاحتياط تلقائيًا ضمن الأسرة، مع إقصاء معلمات من أخذ الاحتياط وسبب غياب حر.
- استيراد الجدول العام من PDF ومراجعة المطابقة صفًّا بصف.
- أسرة العلوم (الفيزياء والكيمياء والأحياء) مع بقاء الأسر الأصلية.
- إحصائيات الغياب (يوم/أسبوع/شهر) مع تقرير مطبوع لكل إحصائية.
- أدوار: مسؤول فني، مديرة المدرسة، مساعدة المديرة، مسؤولة احتياطي الأسرة.
- تطبيق قابل للتثبيت (PWA) على الجوال والحاسوب، ويعمل دون إنترنت.
- جولة توضيحية ودعم فني ونسخ احتياطي.

## التشغيل
- افتح `index.html` مباشرة للتجربة، أو انشره عبر **GitHub Pages** (Settings ← Pages ← Deploy from branch) ليعمل كتطبيق مثبّت عبر https.
- عند أول فتح يُنشأ حساب المسؤول الفني، وتُحفظ البيانات في متصفح الجهاز.
- لا تحتوي هذه النسخة على أسماء الكادر؛ استورد الجدول العام (PDF) من تبويب «استيراد الجدول» لتُبنى القوائم.

## إشعارات الهاتف والتطبيق مغلق (اختياري)
تحتاج خادم إرسال خارجي (Firebase / Cloudflare). ملفات `teacher.html` و`sw.js` جاهزة للربط به.

## الخصوصية
لا ترفع أسماء المعلمات أو جداولهن أو أرقام هواتفهن إلى مستودع عام.
